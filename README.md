# Prompt Atelier

`1girl` を必ず先頭に含める、ローカル専用のランダムプロンプト生成アプリ。

## 起動

`PromptAtelier.html` をダブルクリックしてください。`Start-App.cmd` からも開けます。Node.js・サーバー・インストール・インターネット接続は不要です。終了するときはブラウザのタブを閉じます。

HTML単体を別のPCへコピーしても使えます。設定保存はブラウザのローカルファイル対応に依存します。以前の localhost 版の設定は自動では引き継がれません。ファイルの移動・改名やブラウザの変更でも保存先が変わる場合があります。保存できない場合は画面に案内を表示し、そのまま生成を続けられます。

## 使い方

- 「自由入力タグ」欄に任意のタグ（カンマ区切り）を入力すると、プロンプトの末尾に追加されます。入力内容は保存されます。
- 絵柄項目は Danbooru の絵柄タグ（anime coloring・`watercolor \(medium\)` など（括弧は強調と誤解されないようエスケープ））から選べます。
- アーティスト項目は Danbooru の人気絵師119名を artist:名前 の形式で出力します。
- 各カテゴリ右上のスイッチで、出力への追加を切り替えます。
- 候補を選ぶか「再抽選」で変更できます。「固定する」で候補を保持します。
- 「ランダム生成」は有効で固定されていない項目だけを変更します。再抽選では直前と異なる候補を選びます。
- 固定中は候補選択も停止します。変更するときは固定を解除してください。
- 各カテゴリのタグ表示の横の「コピー」ボタンで、その項目のタグだけをコピーできます。
- 「プロンプトをコピー」で画像生成サービスに貼り付けます。自動コピーに失敗した場合は、選択された結果を Ctrl+C でコピーできます。
- すべて無効でも `1girl` が残ります。設定はこのブラウザ・このURLに保存されます。プライベートブラウズ等では保存されない場合があります。

画像生成、外部API通信、アカウント登録は行いません。タグ候補は同梱され、通常利用はオフラインで動作します。`1girl` の挿入を保証するもので、生成画像の人数は画像生成モデルに依存します。

## 開発・確認

```powershell
npm.cmd ci
npm.cmd run dev
npm.cmd test
npm.cmd run build
```

候補データは `src/data.ts`、生成・保存処理は `src/generator.ts` にあります。UIの保存形式はバージョン2（旧形式の成人向け服装も自動移行）。内容が不正な場合は全項目を初期状態に戻します。開発用サーバーのみ127.0.0.1にバインドします。通常利用ではサーバーを使いません。ビルドすると配布用の単体HTMLをルートとdist/index.htmlに出力します。開発・再ビルドに限りNode.jsと依存パッケージが必要です。

## 追加機能

- 通常候補は各カテゴリ69種類以上です。Danbooru の投稿数上位タグ（髪型・髪色・瞳・表情・服装・ポーズ・背景・構図・ライティング全カテゴリ合計1,633種類）を日本語ラベル付きで追加済みです。再取得は `node scripts/danbooru-options.mjs`（開発時のみ・要ネット接続）。再取得しても既存候補の順序は変わらず、新しいタグは末尾に追加されるため、以前の選択や固定設定を引き継ぎます。追加候補は `scripts/danbooru-extra-tags.mjs`・`scripts/danbooru-more-tags.mjs` に書きます。
- 品質タグは6種類から複数選択でき、再抽選で変わりません。初期状態は未選択です。タグの効果は利用する画像生成モデルに依存します。
- NSFWモードは成人・非露骨のファッション表現向けです。服装に加え、ポーズ・表情・背景・構図・ライティングにも Danbooru の人気タグから非露骨な候補（計193種類）を追加します。露骨な性描写のタグは含めません。水着・ランジェリー・ドレス32種類を服装候補に追加し、adult woman, mature femaleを出力に含めます。通常の服装も引き続き抽選されます。
- NSFWモードをオフにすると、専用の服装を選択していた場合は固定中でも通常候補の先頭に戻します。固定状態自体は維持します。
- 品質タグとモードもブラウザに保存されます。成人タグは画像生成モデルによる年齢表現を保証するものではありません。
